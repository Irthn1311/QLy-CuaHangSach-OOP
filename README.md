# Bookstore Management — OOP Coursework

An early Java Object-Oriented Programming project for managing a small bookstore.

## Scope

The source code is organized around domain modules for:

- books
- authors
- publishers
- customers
- employees
- invoices
- incoming stock / purchase receipts
- user-interface components
